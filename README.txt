KB 단타포착 V2

1) GitHub 저장소의 기존 app.py를 이 app.py로 교체합니다.
2) requirements.txt도 함께 교체합니다.
3) Streamlit Secrets:
   KB_APP_KEY = "본인의 App Key"
   KB_APP_SECRET = "본인의 App Secret"
4) 앱을 재부팅하고 'KB API 인증 테스트'를 누릅니다.

주의:
- App Key/App Secret은 GitHub 코드에 직접 적지 마세요.
- 이 V2는 KB 공식 Client Credentials 요청 형식(JSON)을 사용합니다.
- E021이 계속되면 KB Open API 신청/앱 상태/App Key 발급 상태를 확인해야 합니다.
