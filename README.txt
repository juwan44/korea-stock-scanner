단타포착 - 갤럭시 Streamlit용

1. app.py 와 requirements.txt 를 같은 폴더에 넣습니다.
2. 터미널에서: pip install -r requirements.txt
3. 실행: streamlit run app.py
4. 크롬에서 표시되는 주소를 엽니다.
5. 사이드바에 키움 REST API App Key / Secret Key를 입력합니다.

주의
- API Key/Secret은 다른 사람에게 보내지 마세요.
- 키움 REST API 순위정보 API의 ID/경로가 변경되면 앱의 '고급 설정'에서 최신 공식 명세 값으로 수정해야 합니다.
- 기본값은 모의투자입니다.
- 자동 주문 기능은 포함하지 않았습니다.
